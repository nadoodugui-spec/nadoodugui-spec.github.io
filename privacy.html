개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-11-25

1. 무엇을 쓰는가 / What data is accessed

Mail Agent는 사용자가 Google 로그인 화면에서 허용한 범위(https://mail.google.com/)로, 사용자 본인의 Gmail 메일을 읽고, 정리하고(읽음·이동·삭제), 사용자가 직접 쓴 메일을 보냅니다.

With the permission the user grants on Google's consent screen (https://mail.google.com/), Mail Agent reads the user's own Gmail messages, organizes them (mark read, move, delete) and sends mail the user writes.

2. 어디에 두는가 / Where data is stored

메일 사본과 로그인 정보(갱신 토큰)는 사용자의 컴퓨터에만 저장됩니다. 로그인 정보는 암호화해 둡니다. 개발자나 다른 서버로 보내지 않습니다.

Message copies and sign-in credentials (refresh tokens) are stored only on the user's own computer; credentials are encrypted. Nothing is sent to the developer or any other server.

3. 나누지 않는다 / No sharing

Google 사용자 데이터를 다른 사람에게 팔거나, 넘기거나, 광고에 쓰지 않습니다. 사람이 메일을 대신 읽지 않습니다.

Google user data is never sold, transferred to third parties or used for advertising, and no human reads it on the user's behalf.

Mail Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 지우기·권한 끊기 / Deletion and revoking access

프로그램에서 계정을 지우면 그 계정의 메일 사본과 로그인 정보가 컴퓨터에서 지워집니다. 언제든지 Google 계정의 「타사 앱 및 서비스」에서 Mail Agent 의 권한을 끊을 수 있습니다.

Removing an account in the program deletes its message copies and credentials from the computer. Access can be revoked at any time at Google Account → Third-party apps & services.

This is a personal-use program. Please contact the owner through this site's GitHub repository.
